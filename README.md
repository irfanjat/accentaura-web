# AccentAura – English Accent Identifier

A commercial-grade, minimalist English Accent Identification system developed for academic and exhibition deployment.

## Features
- Real-time acoustic feature extraction (MFCCs, Spectral Centroids, Roll-off, Bandwidth)
- Academic ML classification using Speech Accent Archive dataset
- Clean dark-mode exhibition interface
- Offline desktop application + Cloud web app support
